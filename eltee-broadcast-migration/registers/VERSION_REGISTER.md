## Version numbering

- **Patch, for example v1.1.1:** spelling, punctuation or formatting only. No change to requirements, decisions or controls.
- **Minor, for example v1.2:** approved additions, clarifications, task changes or new evidence that do not replace the migration strategy.
- **Major, for example v2.0:** approved change to scope, source precedence, site architecture, release method or another controlling project decision.
