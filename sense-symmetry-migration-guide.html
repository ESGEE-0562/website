⚠️
Read Before You Start Sense and Symmetry are structurally different themes. Section types, setting IDs, and template schemas do not transfer between them. This guide walks you through everything that needs to be done manually — in order. Do not publish Symmetry until every phase is complete and tested in preview.
Phase 1

Pre-Migration Preparation

Before touching Symmetry, lock down a snapshot of the current live theme and gather what you'll need.

1
Duplicate the live Sense theme

In Shopify Admin → Online Store → Themes, click the ··· menu on Sense 15.4.1 (March 2026) and choose Duplicate. Name it "Sense 15.4.1 – Pre-Symmetry Backup [date]". This becomes your rollback point.

2
Rename the Symmetry theme

Rename the Symmetry demo theme to "Symmetry – Migration WIP" so it's clearly a work-in-progress. Never publish it until Phase 10 is complete.

3
Screenshot every live page

Take full-page screenshots of: Homepage, each Product page, Collection pages, the FAQ page (page.faq-v2), the Erina Store page, and the Demo Videos page. These are your visual reference for QA.

4
Note the Pagetify pages

The live theme contains two large Pagetify bundles: pagetify-page-97139523721 and pagetify-page-97489649801. These CSS/JS files are baked into Sense. Log into Pagetify and confirm which pages use them — those pages will need to be republished from Pagetify into Symmetry.

5
Note: ss- sections are replaced by Symmetry natively

The homepage currently uses sections prefixed ss- (ss-slider-2, ss-hero-24, ss-featured-collection, etc.) from a third-party app. Symmetry has native equivalents for all of them — Featured Collection sliders, Image Banner, Logo List with marquee, Video with Text, and so on. You don't need the ss- app in Symmetry. See the Section Map in Phase 7 for exact replacements.

Phase 2

What Transfers Automatically

These items live in Shopify's data layer, not the theme. They require no action.

Auto Products & Variants

All products, prices, variants, images, descriptions, and metafields are unchanged. Theme migration does not touch product data.

Auto Collections

All manual and smart collections, including the cart drawer collection (best-period-underwear), transfer as-is.

Auto Pages & Blogs

All page content, blog posts, and article bodies remain in Shopify. Their URLs, handles, and SEO meta titles/descriptions are unaffected.

Auto Product SEO

Page titles, meta descriptions, and URL handles on every product, collection, and page are stored in Shopify — not in theme files. Nothing to do.

Auto Navigation Menus

Main menu, footer menus, and any other link lists are in Shopify Admin → Navigation. They'll work in Symmetry immediately.

Auto Customer Accounts

All customer accounts, order history, and addresses live in Shopify. Unaffected by theme changes.

Phase 4

SEO & Structured Data — Critical

🔴
This is the most important phase. The live Sense theme.liquid contains extensive custom JSON-LD structured data that does not exist in any standard theme. It must be manually copied into Symmetry's theme.liquid. Missing this breaks rich results in Google Search for the homepage, store page, FAQ, articles, and collection pages.
Critical Schemas currently embedded in Sense's theme.liquid
Homepage
  • Organization — Eltee Sydney entity, social links, aggregate rating
  • ClothingStore — Erina physical store (AU/NZ only)
  • WebSite — with SearchAction for Shopify search
  • VideoObject — Founder video
  • VideoObject — Real blood test video
Other Pages
  • Article — article template article.sons-coach
  • VideoObject — article eltee-sydney-period-swim-comparison
  • ClothingStore — page handle erina-store
  • VideoObject ×7 — page handle period-undies-demo-videos
  • ItemList — all collection pages
  • FAQPage — template page.faq-v2 with 14 Q&As
Critical Step-by-step: transfer the schema to Symmetry
1
Open both theme files side by side

Go to Shopify Admin → Online Store → Themes. On Sense 15.4.1, click ··· → Edit code → layout/theme.liquid. Leave this tab open. Open a second browser tab and do the same for Symmetry (Migration WIP) → Edit code → layout/theme.liquid.

2
Copy the Pinterest meta tag first

In Sense's theme.liquid, use Cmd+F (Mac) or Ctrl+F (Windows) to search for p:domain_verify. Copy the entire line:

<meta name="p:domain_verify" content="c74d47d6c4801cc26977c8dc5c005912"/>

In Symmetry's theme.liquid, find the opening <head> tag and paste this as the very first line inside it.

3
Find the start of the JSON-LD block in Sense

In Sense's theme.liquid, search for application/ld+json. Scroll up a few lines from the first result until you see:

{% if template == 'index' %}

That line is the beginning of your entire schema block.

4
Find the end of the JSON-LD block

Scroll down from the {% if template == 'index' %} line through all the schemas — Organization, ClothingStore, WebSite, VideoObjects, Article, ItemList, FAQPage — until you reach the final </script> tag that closes the FAQPage schema. That closing tag is the end of your selection.

Select everything from {% if template == 'index' %} to that final </script>. Copy it all.

5
Paste into Symmetry's theme.liquid

In Symmetry's theme.liquid, search for </head>. Paste the entire copied block immediately before that closing tag. Save the file.

6
Copy the CodeUp / GA4 head scripts

Still in Sense's theme.liquid, find the CodeUp app block — a Liquid render or section tag near the top of <head> that outputs your GA4 tag and other head scripts. Copy it. Paste it in the same position in Symmetry's theme.liquid. Save.

7
Verify GA4 is firing on Symmetry preview

Open the Symmetry preview URL in Chrome. Open DevTools → Network tab and filter by collect or open GA4 → Admin → DebugView in a second tab. Navigate between the homepage, a product page, a collection page, and the FAQ page in the preview. Confirm a page_view event fires on each template type before moving on.

8
Run Google Rich Results Test on 5 pages

Go to search.google.com/test/rich-results. Use the Symmetry preview URL format: https://elteesydney.com.au/?preview_theme_id=154441416841&path=/your-page. Test all five:

  • Homepage — expect Organization, ClothingStore, WebSite, VideoObject
  • /pages/erina-store — ClothingStore
  • /pages/faq — FAQPage with all 14 Q&As
  • /pages/period-undies-demo-videos — 7 × VideoObject
  • Any collection page — ItemList

All five must pass with no errors before Stage 6 (publish).

ℹ️
Aggregate rating The Organization schema hardcodes reviewCount: "486". Update this figure before publishing — it directly influences Google's rich snippet display.

Phase 6

Custom Assets & Code

Three categories of custom code exist in the live theme that need to be carried over.

Critical base.css — modified 15 June 2026

The base CSS file has been modified from the Sense default. Identify which CSS rules were added or changed (compare against a clean Sense 15.4.1 base.css). Those custom rules need to be added to Symmetry via:

  • Symmetry's built-in CSS customisation field in Theme Settings, or
  • A custom CSS file uploaded via the CodeUp app (already in use)

Do not copy base.css wholesale — Symmetry's base.css is completely different. Only extract the custom additions.

Critical section-image-banner.css — modified 9 June 2026

Custom overrides were applied to the image banner section CSS. Compare against the clean Sense version to extract those rules, then add them to Symmetry's equivalent banner section styling or via custom CSS.

The custom rule hiding the desktop banner on mobile and vice versa (@media (max-width: 767px) {.banner {display: none;}}) is set inline on the sections themselves in the template — those will need to be re-applied section by section in Symmetry.

Manual AI-Generated Blocks (ai_gen_block_*.liquid)

Five AI-generated liquid block files exist in the live theme. The most important is ai_gen_block_bb3c871.liquid — the founder video + text section used on the homepage.

  • Download all five blocks/ai_gen_block_*.liquid files from the Sense theme
  • Upload them to Symmetry via Edit Code → blocks/ folder
  • They can then be added back via the theme editor
Note Pagetify Assets

The files pagetify-page-97139523721.css and pagetify-page-97489649801.js (413KB and 457KB respectively) are Pagetify-generated bundles. The Pagetify app manages these — you do not need to copy them manually. Simply republish the affected Pagetify pages while Symmetry is active to regenerate them.

ℹ️
en.default.json was modified (27 May 2026) The English locale file in Sense has custom string overrides. Compare it against the Sense default to extract any changes, then apply the same overrides to Symmetry's locale file. Common customisations include add-to-cart button text, sold-out labels, and cart strings.

Phase 10

CRO Improvements During Migration

Your June 2026 GA4 audit identified specific friction points. The migration to Symmetry is the right moment to resolve them — new theme, clean slate. Work through these before launching.

⚠️
P1 — Fix Before You Publish Two tracking issues in the current GA4 data are masking your actual funnel performance. Both need to be resolved in Symmetry before you can trust any post-migration reporting.
P1 Urgent Fix GA4 "(not set)" Landing Page Tracking

65% of sessions (106,771 of 163,785) have no landing page recorded in GA4. This makes attribution unreliable across all channels. Likely causes: cross-domain mismatch between elteesydney.com.au and elteesydney.com, or the GA4 page_view event not firing on initial load for some entry paths.

During migration: When you copy your CodeUp (or GTM) head scripts into Symmetry's theme.liquid, test immediately that page_view fires on every template — homepage, product, collection, blog, and page. Use GA4 DebugView. Also verify cross-domain linking is set up correctly in GA4 Admin → Data Streams → Configure tag settings → Configure your domains.

P1 Urgent Verify add_to_cart Event on All Products

The 3 Pack shows 441 purchases but 0 tracked add_to_cart events — the event is not firing for that product configuration. The CHOOSE YOUR POOL PERFECT COMBO has 908 add_to_cart events and $0 revenue, which suggests a checkout or availability fault.

Before publishing Symmetry: Test add_to_cart firing for: UnderSwim (standard), UnderSwim G-Fit, 3 Pack (critical — currently broken), and CHOOSE YOUR POOL PERFECT COMBO. For the Combo, check whether it's marked available, has a valid price, and can reach checkout without error. Fix before launch — this is estimated at up to $81K in unblocked revenue.

P2 High Mobile Product Page — Sticky ATC

Mobile purchase CVR is 3.8% vs desktop 9.3% — a 2.5× gap. 92% of traffic is mobile. The primary fix is ensuring the Add to Cart button is always visible on mobile without scrolling.

In Symmetry: Symmetry has native sticky ATC support. In the product template editor → Main product section, look for "Sticky add to cart" or "Sticky header" and enable it. This alone is the highest-leverage single setting change in this entire migration.

P2 High Social Proof Above the Fold on Mobile

88.5% of product page viewers don't add to cart. On mobile, social proof (reviews star rating) is likely not visible without scrolling, removing the trust signal at the moment it matters most.

In Symmetry product template: Place the Klaviyo Reviews Average Rating block immediately after the product title — before price, before description, before variant picker. Check this in mobile preview. The star rating should be the second thing a mobile visitor sees after the product name.

P2 High Size Guide Visible Near Variant Picker

521 visitors landed directly on /pages/size-chart with a 70.6% bounce — they arrived, checked sizes, and left without buying. Size uncertainty is a documented barrier for this product category.

In Symmetry product template: Add a size guide link or inline popup directly adjacent to the size variant picker. Most Symmetry size guide apps or custom liquid blocks can render a link that opens a modal. Do not make users navigate away from the product page to check sizing. Also update the size chart page itself with a prominent "Shop UnderSwim" / "Shop UnderDance" CTA at top and bottom.

P2 High Cart Drawer — Shipping & Returns Reassurance

60.5% of ATCs don't begin checkout. Cart-to-checkout abandonment at this rate typically means shipping uncertainty or first-buyer anxiety.

In Symmetry cart drawer settings: Add a shipping threshold bar (e.g. "Free shipping over $X"). Add a one-line returns reassurance — "Free returns · Easy exchange" — near the checkout button. Symmetry's cart drawer supports announcement text; use it. Also confirm Apple Pay and Shop Pay express buttons are showing in the drawer on mobile (this removes friction for returning buyers).

P3 Medium Collection Pages — Intro Copy & Mobile Grid

/collections/girls-period-swimwear has a 71.6% bounce rate and 4.3% CVR. Collection pages are bouncing because they don't explain which product to choose — they just show a grid.

In Symmetry: Add a collection banner section with intro copy that distinguishes products (e.g. UnderSwim vs Period Swim Bikini Bottom). Symmetry collection templates support a header image + text section natively. On mobile, ensure product cards show use-case context — not just product name and price. Consider adding a "best for" badge or subtitle to each product card.

P3 Medium Homepage Routing — Keep What's Working

The homepage has a 15.1% CVR and only 37% bounce rate — it's the strongest-converting landing page on the site. Don't redesign what's working.

Preserve in Symmetry: The current homepage routing structure (hero → sport pathways → product slider → proof) is doing its job. Ensure the sport-specific pathways (swimming, dance, netball, school) remain clearly signposted above fold. If Symmetry's hero section supports multiple CTAs, use them: "Shop swim" and "Shop dance" alongside the main CTA, rather than a single generic "SHOP NOW".
